# 最终验证报告

## 发布决定

**PASS 用于独立运行的 Linux x86_64 演示和平台
集成包。** 该包对于其声明的公共数据来说是完整的，
工作流程资格、合成发酵、CPU-模型和KG-交换范围。
**未**针对真实世界的发酵预测、因果菌株进行验证
选择、部署的知识图或湿实验室CRISPR/GPA生产。

活动版本仅包含以下运行命名空间：

| 运行 | 目的 | 验证 | 产物数 |
|---|---|---:|---:|
| `ec_b36_cenpk_full_4omics_x86_v2` | 大肠杆菌 B36 和酵母CEN.PK113-7D，所有四种组学类型和扩展 | 1,296 / 1,296 PASS | 318 |
| `yrc_bc187_yjm981_dna_portability_v2` | 独立BC187和YJM981双端DNA适配器测试 | 160 / 160 PASS | 38 |
| `prjeb55673_wt_single_end_rna_portability_v1` | 独立完整的单端碱基空间酵母RNA适配器测试 | 104 / 104 PASS | 24 |

主要工作流程有 39 个基准 Snakemake 阶段。其孤立的公众
方法重放完成了 25 / 25 项作业并发出了 10 个受控模块的结果。
最终更改后，所有三个运行配置都通过了`doctor`；每场决赛
Snakemake 试运行报告称每个请求的输出都存在并且是最新的。

## 包和依赖资格

- 本地原始输入：66 个物理文件，12,374,772,764 字节。
- 本地参考资产：77 个物理文件，340,192,832 字节。
- 离线依赖库：1,426个物理文件，3,131,398,240字节。
- 脱机包存储库校验和清单中的所有 982 项均已
  同步更新的 Orchestrator 锁条目后重新哈希成功。
- 离线安装程序被运用到独立的一次性运行时中。全部
  所需的 Python 模块以及排序、R、关联、XCMS、Sage 和
  Linux x86_64 上的编排命令通过`doctor`。
- 活动包不包含符号链接，也不包含多重链接文件。
  用于选择输入的路径是与包相关的，并且预检会拒绝以下路径：
  逃离存储库。执行日志可能会保留其中的绝对目录
  命令运行；这些是出处字符串，而不是输入依赖项。
- 每个不可变的版本校验和清单都被重新读取，每个列出的文件都被重新读取
  重新哈希：1,343 个主要文件、207 个DNA-可移植性文件和 117 个RNA-可移植性文件，其中
  零丢失文件和零不匹配。仅附加事件流和发布
  完成标记被明确排除，因为它们的终端记录是
  写在不可变快照之后。
- 仪表板阶段和最终摘要是分开的。这可以防止释放
  修改验证的输入并消除先前的永久
  验证/释放重新运行循环。

## 模态结果

### DNA测序

- 观察到的 B36：两个候选单倍体和两个通过的高置信度单倍体调用；
  最小通过等位基因分数 0.90；所有经过的行都有可解释的GFF
  注释和真正的 0/1 单倍体剂量。
- CEN.PK113-7D：1,458 个候选变异，其中 320 个通过等位基因比例等筛选
  0.80；所有传递的行都有可解释的注释。
- B36 阳性对照测试数据包含八种设计变体，并产生
  非空变异调用器回归VCF。它被标记为`model_derived`，仅用于
  使FASTQ-到-VCF恢复合格，并且被排除在生物学比较之外，
  GWAS/QTL、GEM约束、发酵、预测和KG声明。
- 独立可移植性：BC187 产生 37,080 个候选变异，其中 35,994 个通过筛选；
  YJM981 产生 46,597 个候选变异，其中 44,485 个通过筛选。两者均已声明
  等位基因分数阈值 0.80 和 100% 可解释的通过行的单倍体。

### RNA测序

- B36：5,118 TPM 行，5,044 个非零；注释/显示标签覆盖率 100%。
- CEN.PK113-7D：5,451 TPM 行，5,448 个非零；注释/显示标签覆盖率
  100%.
- 独立单端`ERR10125429`：6,459个参考行，检测到2,364个
  基因和 100% 可解释的标签。其ENAMD5，gzip完整性，FASTQ
  结构和碱基空间字母表在本地进行检查。
- 可移植性运行暴露了真核生物“GFF/SAF”关键优先级不匹配。的
  标准化器现在接收`annotation_model`并应用相同的标识符规则
  作为参考一代。配对 B36 和 CEN.PK TPM 的回归输出
  表保持字节相同。
- 之前暂存的 YRC RNA 文件被正确检测为遗留 SOLiD
  颜色空间输入。它们保留在`data/unsupported/`下，并带有预检
  拒绝而不是重新标记或静默零条测序读段输出。

### 蛋白质组学

- B36：2,022 个定量蛋白质； CEN.PK113-7D：2,506。注释/显示覆盖范围
  在两个发布的丰度表中均为 100%。
- 提供的锚点仅在精确的本地RAWSHA-256之后重用经过验证的Sage缓存
  验证。新分析的 Sage 分支仍然可执行，但被序列化为
  一项作业，上限为 4 个线程，受 12 GiB RSS / 14 GiB 虚拟内存限制，
  如果主机可用内存低于 8 GiB，则停止。
- 缓存发布元数据现在分离历史缓存生成来源
  （发生在ARM64）来自当前的 x86 运行。面向用户的搜索参数
  指向本地RAW/搜索资产并明确声明 Sage 不是
  在本次运行中启动。受保护的包装器的后备指向捆绑的 x86
  圣人二进制。

### 代谢组学

- B36：23,782 个重新处理且保持匿名的 MS 特征，另有 170 条独立来源的发布方命名结果；命名结果的外部标识符覆盖率为 97.65%。
- CEN.PK113-7D：2,676 个重新处理且保持匿名的 MS 特征，另有 367 条发布方命名结果；命名结果的外部标识符覆盖率为 97.28%。
- 在发布者命名的图层中，代谢物名称覆盖率为 100%。匿名原始
  功能保持匿名，因为现有证据不能证明
  一对一的身份分配。这两层有单独的表、清单、
  和图形语义。

## 比较和多组学整合

- B36 与 MS14384 具有非空DNA、RNA、蛋白质和代谢物表（3,384；
  5,357； 4,657；和 283 行证据）。这是公开处理的同一研究
  证据，而不是新的匹配的原始重新分析。
- YRC 与 CEN.PK113-7D 具有非空DNA、RNA、蛋白质和代谢物证据
  表（3、6,465、2,835 和 585 行）。这是交叉研究证据对齐；
  使用数据集内百分位数而不是无效的直接折叠更改。
- 主要整合交换包含两个生物样本和一个 41,877
  特征词典。源层、生物体、测定、稳定标识符、单位、
  失踪，并保留资格。跨组织特征计数不是
  被视为生物对比。

## 延伸分析

| 模块 | 执行结果 | 解释边界 |
|---|---|---|
| 细菌GWAS | 新鲜的 EcoRef 重播：160 个菌株、16,530 个存在/不存在特征、10,040 个有限关联行 | 外部子集和接口限定，而不是 B36 特定的因果关系 |
| 酵母QTL | 重新执行 Bloom 分析：4,331 个表型样本，5,000 个分析标记；包含亲缘关系校正 LMM 和明显膨胀的未校正诊断 | 外部队列；应使用校正结果，未校正结果只用于诊断 |
| 分子QTL | 带有重叠表的新鲜公共 eQTL 和作者处理的 pQTL 输出 | 分开符合条件的群组，而不是两个锚 |
| WGCNA | 814个样本，500个特征，四个模块，包括灰色，一个特征 | 特征广度有限的网络可行性；非因果关系 |
| MOFA2 | 814 个匹配样本，100 RNA + 100 个蛋白质特征，5 个因子，19 次拟合迭代 | 无监督的外部队列结构；无表型声明 |
| DIABLO | `DEFERRED_NO_PREDECLARED_TARGET` | 正确的故障关闭行为；没有发明标签 |
| GEM / MEMOTE | 新鲜 iML1515 和酵母-GEM 加载，FBA/pFBA/FVA 和MEMOTE 摘要 | 已发布模型执行/QC；没有目标产品优化 |
| CRISPR | 公共GSE159409文库/计数验证：56,768个靶标、51,681个独特指导、6,685个基因、20个样本 | 描述性的公共处理证据，而不是包装菌株的筛选 |
| 发酵 | 合成测试数据：280批次，7个菌株，510,240个工艺行，1,400个表型行 | 仅接口和验证测试数据 |
| CPU预测 | 1,000 个合成行，250 个菌株组，五组折叠； MLP，岭，随机森林和训练平均基线 | 零观察到的组学与发酵连接；不可部署的性能 |
| KG 交换 | 48,572 个节点、55,249 条边、唯一节点 ID，且所有端点均可解析 | 交换/完整性可行性，而不是图数据库服务或因果引擎 |

最好的合成MAE恰好是随机森林（0.357），而不是MLP
（2.272）。该结果是报告的而不是隐藏的，但这两个值都没有
现实世界的预测意义。真正的建模在足够的情况下仍然受到阻碍
匹配观察到的组学、菌株/活动组、过程轨迹和终点
提供发酵结果。
