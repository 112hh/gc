## 原型交互

- 默认进入“分析任务列表”；点击真实复现任务 `MO-20260806-001` 可进入当前的任务详情、节点状态和结果页。
- 点击“新建分析任务”先选择任务方式：标准组学分析、申请建立复现模板、严格复现；随后进入基本信息、选择数据、分析方案、审核与提交。
- 常规的新建任务由用户直接登记本次实验的原始文件、样本映射和实验元数据；数据完整性校验与数据审核通过后，才进入计算队列。分析环境由平台后台统一维护，复现包仅用于示例任务而非日常任务前置条件；节点由分析服务器回传，自动校验与专家复核后才能生成工程设计和验证任务。
- 设计/发酵验证结果回写至项目知识网络，作为下一轮 DBTL 分析的输入，形成业务闭环。
- 点击“复现过程与节点状态”的任一节点，查看输入、工具、关键结果、输出和对应需规功能。
- 点击顶部三个标签，切换复现总览、模型与预测、成果交付与需规映射。
